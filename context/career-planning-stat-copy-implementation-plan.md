# 장기적 진로설계 5.4% 통계 문구 정정 구현 계획

정본 설계: `docs/superpowers/specs/2026-08-17-career-planning-stat-copy-design.md`

1. 운영 저장소 최신 `main`에서 `5.4%`와 장기적 진로설계 통계가 쓰인 웹, 문서, 배포 PDF 위치를 전수 확인한다.
2. `/career-check` 통계 카드를 승인 문안으로 수정하고 기존 출처·표본·링크를 보존한다.
3. 근거 문서와 PDF 제작 명세의 정의 및 해석 주의를 승인 원칙에 맞춰 통일한다.
4. 배포 PDF의 해당 통계 페이지를 같은 문안으로 수정하되 기존 디자인과 나머지 페이지를 보존한다.
5. 텍스트 검색, 웹 lint·타입 검사·빌드, PDF 텍스트 추출 및 전체 페이지 렌더링으로 회귀와 시각 결함을 검증한다.
6. 변경 파일만 커밋하고 CDKorea PR 검사 통과 후 `main` 병합 및 Vercel production의 웹·PDF 노출을 확인한다.
