# 신앙과 소명 카드뉴스 운영 기준

이 문서는 승인된 `소명은 직업보다 큽니다` 5장 산출물의 구현 기록과 이후 카드뉴스의 운영 기준을 함께 정리한다. 해당 5장은 브랜드 방향을 보여주는 기준 사례이며 모든 콘텐츠에 동일한 장수와 좌표를 강제하는 고정 템플릿이 아니다. 최상위 설계 기준은 Drive의 [`flexible-card-news-design-spec.md`](https://drive.google.com/file/d/198KjjQ6fSWfFPz8-vOh4VK_IqRUXQxWo/view)다.

1. 콘텐츠 문안을 표지·문제·근거 또는 관점·해결 기준·단일 CTA의 역할로 나눈다.
2. 기본은 5장으로 하되 내용에 따라 4~8장 중 적정 장수를 선택하고 이유를 기록한다.
3. Career Direct 공식 로고와 딥 틸·화이트·샌드 골드 중심 팔레트를 사용해 1080×1350 편집 원본을 제작한다.
4. 실제 장수 전체를 PNG로 렌더링하고 몽타주로 색상·타이포·여백·번호 체계를 검수한다.
5. 오버플로·잘림·의도하지 않은 겹침을 검사하고 수정한다.
6. 승인 원본 PPTX, 기준 PNG, 몽타주는 콘텐츠 운영 폴더의 `04-브랜드-템플릿`에 저장한다. 캠페인 산출물 폴더에는 수동 발행용 복사본만 둔다.

## 검증 기준

- 모든 페이지가 1080×1350이다.
- 카드뉴스는 4~8장이며 파일 수와 페이지 번호의 전체 장수가 일치한다.
- 딥 틸·화이트·샌드 골드를 중심으로 사용하되 주제에 따라 배경과 강조 비율을 조정할 수 있다.
- 공식 로고의 비율과 색상은 고정하지만 배치 위치는 레이아웃에 맞게 조정할 수 있다.
- 페이지 번호는 전체 순서를 표시하되 위치와 표현을 레이아웃에 맞게 조정할 수 있다.
- 기존 원고의 신학적 경계와 단일 CTA가 보존된다.
- 모든 텍스트가 모바일 축소 화면에서도 읽히고 슬라이드 밖으로 넘치지 않는다.
