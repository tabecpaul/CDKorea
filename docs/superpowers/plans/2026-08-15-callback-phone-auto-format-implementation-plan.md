# 콜백 전화번호 자동 포맷 구현 계획

1. 국내 휴대전화 숫자를 입력 길이에 맞춰 하이픈 형식으로 바꾸는 순수 함수를 추가한다.
2. 숫자 길이, 기존 구분 문자, 붙여넣기와 최대 길이를 다루는 단위 테스트를 작성하고 실행한다.
3. 콜백 폼의 전화번호 입력을 제어 입력으로 전환해 포맷 함수를 연결한다.
4. 린트, TypeScript와 프로덕션 빌드를 실행한다.
5. 모바일·데스크톱 브라우저에서 숫자 입력, 삭제와 제출값을 확인한다.
6. CDKorea 전용 브랜치에 커밋·푸시하고 PR 검사를 통과한 뒤 운영 배포한다.
7. 확정된 정보로 실제 콜백 테스트를 한 번 제출하고 성공 화면과 기록 경로를 확인한다.
