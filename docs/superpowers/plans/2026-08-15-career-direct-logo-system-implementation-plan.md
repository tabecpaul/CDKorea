# Career Direct 공식 로고 적용 구현 계획

1. 제공된 공식 PNG 7종을 웹 공개 브랜드 자산 경로에 복사하고 파일 무결성과 크기를 확인한다.
2. 밝은 배경용 컬러형과 어두운 배경용 화이트형을 선택하는 공용 `CareerDirectLogo` 컴포넌트를 구현한다.
3. `PageHeader`, 일반 `Footer`, `OfficialFooter`, `CareerCheckLanding`의 기존 로고를 공용 컴포넌트로 교체하고 `Korea` 표기를 유지한다.
4. 기존 로고 직접 참조와 변경 범위를 점검하고 린트·TypeScript·프로덕션 컴파일을 실행한다.
5. 주요 화면을 모바일과 데스크톱 크기로 확인하고 로고 비율, 대비, 정렬을 보정한다.
6. 로고 작업 파일만 선별해 커밋하며 기존 사용자 미추적 파일은 보존한다.
