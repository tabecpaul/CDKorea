# 관리자 콜백 목록 표 가독성 개선 구현 계획

1. 한국시간 기준 목록용 날짜와 시간을 각각 반환하는 순수 포맷 함수를 추가한다.
2. 오전·오후, 자정·정오와 초 제거를 검증하는 단위 테스트를 작성한다.
3. 신청일과 확정 일정 셀을 날짜·시간·상태의 세로 구조로 변경한다.
4. 표 최소 폭, 셀 좌우 여백과 열별 줄바꿈 규칙을 조정한다.
5. 린트, TypeScript와 프로덕션 빌드를 실행한다.
6. 1280px와 모바일 화면에서 상태 열 노출과 표 내부 스크롤을 검증한다.
7. 변경 파일만 커밋하고 CDKorea PR·Vercel 운영 배포를 진행한다.
