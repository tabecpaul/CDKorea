# Canva 진로 방향 자가진단 PDF 교체·최적화 설계

## 목적

무료 진로방향 자가진단 다운로드 파일을 Canva에서 내보낸 `Career Direct Korea 진로 방향 자가진단.pdf`로 교체한다. Canva 원본의 내용과 디자인을 변경하지 않으면서 웹 다운로드와 일반 인쇄에 적합하도록 파일 크기를 현재 약 4.3MB에서 1~2MB 수준으로 줄인다.

## 정본과 제공 경로

- 입력 정본: `/Users/m4pro/Downloads/Career Direct Korea 진로 방향 자가진단.pdf`
- 저장소 제공 파일: `apps/www/private-assets/career-direction-check-ko-v1.0.pdf`
- 다운로드 API와 토큰 검증 방식은 변경하지 않는다. API가 같은 저장소 경로를 읽으므로 파일만 교체한다.
- 사용자 다운로드 파일명 `career-direction-check-ko-v1.0.pdf`도 유지한다.

## 콘텐츠 보존 조건

- 전체 12페이지와 A4 페이지 크기를 유지한다.
- 3페이지의 `진로 불안 37.6%`와 `직무 적합성 불일치 59.9%`를 포함해 Canva 원본의 모든 문구를 유지한다.
- 글꼴, 색상, 배치, 선, 체크박스, QR 코드 및 링크를 시각적으로 변경하지 않는다.
- 텍스트 선택·검색 가능성과 기존 링크 동작을 가능한 한 유지한다.
- PDF에 페이지를 추가하거나 워터마크, 메타데이터 문구 또는 임의 콘텐츠를 삽입하지 않는다.

## 최적화 방식

권장안인 균형 최적화를 적용한다.

1. 중복·미사용 PDF 객체와 불필요한 편집용 리소스를 정리한다.
2. 이미지는 일반 화면과 A4 인쇄에서 선명도가 유지되는 범위로만 재압축한다.
3. 텍스트와 벡터 요소는 가능한 한 래스터 이미지로 변환하지 않는다.
4. 1~2MB 목표를 우선하되, 목표 용량을 맞추기 위해 눈에 띄는 화질 저하를 허용하지 않는다. 품질을 지키기 위해 필요하면 2MB를 소폭 초과할 수 있다.

## 검증

- 최종 PDF를 다시 열어 12페이지, A4, 비암호화 상태를 확인한다.
- 원본과 최적화본의 페이지별 텍스트를 비교해 누락 또는 변경이 없는지 확인한다.
- 모든 페이지를 PNG로 렌더링해 잘림, 번짐, 겹침, 글꼴 깨짐, 선 손실이 없는지 확인한다.
- 3페이지 통계와 12페이지 QR 코드를 원본과 시각 비교한다.
- 링크 수와 대상이 원본과 동일한지 확인한다.
- 최종 파일 크기와 SHA-256 해시를 기록한다.
- 웹 lint와 production build를 실행해 파일 교체가 다운로드 경로에 영향을 주지 않는지 확인한다.

## 범위 제외

- 웹사이트 통계 카드 문안의 추가 변경
- 다운로드 토큰, 리드 수집, 이메일 또는 분석 로직 변경
- Canva 원본 콘텐츠의 교정이나 재디자인
- PDF 버전 번호 또는 다운로드 파일명 변경

## 완료 기준

- 다운로드 API가 최적화된 Canva PDF를 제공한다.
- 최종 PDF가 원본의 12페이지 콘텐츠와 시각 품질, 검색 가능한 텍스트 및 링크를 보존한다.
- 파일 크기가 품질을 해치지 않는 범위에서 약 1~2MB로 감소한다.
- 기존 브랜드·운영 구조와 사용자 변경사항에 다른 변동이 없다.
