# 은사·재능·강점 콘텐츠 패키지 설계

## 1. 목적

2026년 8월 27일 발행 예정인 `은사·재능·강점` 콘텐츠를 첫 Google Drive 완성 패키지로 준비한다. 공식 사이트 원문을 기준으로 네이버 블로그, Facebook·Instagram, Threads와 카드뉴스를 채널에 맞게 재구성하고, 관리자 대시보드에서 수동으로 가져와 검토할 수 있게 한다.

이 작업은 콘텐츠를 자동 승인하거나 게시하지 않는다. Drive 가져오기 Cron과 외부 채널 자동 발행도 활성화하지 않는다.

## 2. 기존 기준

- 캠페인: `faith_calling_series_2026q3`
- 주제: `은사·재능·강점`
- 발행일: 2026년 8월 27일(KST)
- 일정: 네이버 08:00, Facebook·Instagram 19:00, Threads 21:00
- 단일 CTA: 무료 진로 방향 자가진단
- 네이버 카테고리: `이직·커리어 전환`
- 카드뉴스: 1080×1350 PNG 8장
- 시각 기준: Drive의 `flexible-card-news-design-spec.md`와 `04-브랜드-템플릿`

8장은 최신 허용 범위인 4~8장에 포함된다. 영적 은사, 재능, 기술, 강점을 구분하고 성경적 관점과 Career Direct의 역할 한계를 함께 설명하기 위해 기존 8장 구조를 유지한다.

## 3. 콘텐츠 구조

### 공식 사이트

`/blog/gifts-talents-strengths`를 기준 원문으로 준비한다. 다음 내용을 충분히 설명한다.

1. 잘하는 일이 곧 소명이라는 오해
2. 영적 은사, 재능, 기술, 강점의 구분
3. 공동의 유익과 청지기 관점
4. Career Direct의 성격·흥미·재능·가치관과 영적 은사의 차이
5. 실제 경험과 공동체 안에서 확인할 점검 질문
6. 무료 진로 방향 자가진단 CTA

성경 인용은 기존 초안의 고린도전서 12장 4–7절과 베드로전서 4장 10–11절 범위 안에서 사용한다. Career Direct가 영적 은사나 하나님의 뜻을 판정한다고 표현하지 않는다.

### 네이버 블로그

공식 원문을 그대로 복제하지 않고 사례, 구분표, 자기점검 질문을 중심으로 충실한 장문으로 재구성한다. CTA 링크는 네이버 편집기에서 직접 연결하며 모바일에서 신청 화면이 열리는지 확인하도록 발행 체크리스트에 명시한다.

### Facebook·Instagram

기존 `campaigns/faith-calling-series-2026q3/copy/instagram-facebook.md`의 03번 초안을 기준으로 한다. 공식 원문 URL을 실제 페이지와 연결하고 CTA는 무료 진로 방향 자가진단만 유지한다.

### Threads

공식 원문의 핵심 논지를 짧은 연속 게시물로 재구성한다. 개념을 과도하게 단순화하거나 새로운 주장을 추가하지 않으며, 마지막 게시물만 무료 진로 방향 자가진단 CTA로 연결한다.

### 카드뉴스

기존 8장 문안 역할을 유지한다.

1. 표지
2. 먼저 기억할 원칙
3. 영적 은사와 재능
4. 기술과 강점
5. 공동의 유익
6. 선한 청지기
7. Career Direct의 역할
8. 무료 진로 방향 자가진단 CTA

딥 틸·화이트·샌드 골드, 타이포그래피, 안전 여백, 로고와 페이지 번호 체계를 유지하되 승인 사례의 좌표를 기계적으로 복제하지 않는다.

## 4. Drive 완성 패키지

`05-주간-검토-패키지` 아래에 전용 폴더를 만들고 다음 파일만 둔다.

- `content-package.json`
- 공식 사이트 기준 원문
- 네이버 원고
- Facebook·Instagram 문안
- Threads 문안
- 카드뉴스 PNG 8장(배열 순서와 파일 순서 일치)
- 편집 가능한 디자인 원본 또는 Canva 디자인 URL

manifest는 `docs/marketing-content-package-manifest.md`의 스키마를 그대로 사용한다. 패키지 ID는 전역에서 한 번만 사용하며, 모든 파일 ID는 비공개 운영 루트 안의 파일만 가리킨다.

## 5. 검토와 발행 흐름

1. 완성 패키지를 Drive에 저장한다.
2. 관리자가 대시보드에서 `Drive 패키지 가져오기`를 수동 실행한다.
3. 가져온 버전은 `review_pending` 상태로 둔다.
4. 관리자가 원고, 이미지 순서, CTA, UTM과 일정을 검토한다.
5. 수정이 필요하면 Canva 또는 원고를 수정하고 새 버전으로 가져온다.
6. 승인 전에는 어느 채널에도 게시하지 않는다.
7. 네이버는 관리자가 수동 발행하고 링크를 모바일에서 확인한다.

## 6. 검증 기준

- 공식 사이트 주소가 실제 콘텐츠를 반환한다.
- 모든 채널의 CTA가 `/career-check`와 채널별 `organic_social` UTM으로 일치한다.
- 네이버 카테고리가 `이직·커리어 전환`이다.
- PNG가 정확히 8장이고 모두 1080×1350이다.
- 카드 순서와 manifest 이미지 배열 순서가 일치한다.
- 공식 원문, 네이버, SNS 사이에 핵심 정의와 면책 표현이 충돌하지 않는다.
- 수동 가져오기가 한 콘텐츠 버전만 생성하고 재가져오기 중복을 차단한다.
- 자동 승인, 자동 게시와 Drive Cron은 비활성 상태다.

## 7. 제외 범위

- 새로운 캠페인이나 CTA 추가
- 네이버 자동 발행
- Meta·Threads 게시 API 활성화
- Drive 가져오기 Cron 활성화
- 광고 집행 또는 광고 성과 판단
- 고객 기록 및 컨설턴트 성장 파일럿 자동화
