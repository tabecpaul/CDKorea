# start 루트 자가진단 리디렉션 설계

## 문제

`start.careerdirect.kr/`은 공식 사이트 호스트 라우팅에서 예외 처리되어 과거 `Discover God's Design` 랜딩 화면을 계속 표시한다. 전환 전용 도메인의 현재 목적과 맞지 않으며 더 이상 공개할 필요가 없다.

## 변경

- `start.careerdirect.kr/` 요청을 `https://start.careerdirect.kr/career-check`로 308 리디렉션한다.
- 원래 요청의 쿼리 문자열을 그대로 보존한다.
- `/career-check`, 콜백, 결제, 관리자, API, 정적 파일과 공식 사이트 라우팅은 변경하지 않는다.
- 과거 루트 페이지 파일은 다른 내부 의존 가능성을 고려해 삭제하지 않고 공개 호스트에서만 접근되지 않게 한다.

## 검증

- start 호스트의 `/`가 `/career-check`로 308 응답하는지 확인한다.
- UTM 쿼리가 리디렉션 목적지에 유지되는지 확인한다.
- start 호스트의 `/career-check`가 리디렉션 반복 없이 정상 렌더링되는지 확인한다.
- www 공식 루트와 기존 호스트 간 리디렉션 테스트가 유지되는지 확인한다.

## 완료 조건

- 주소창에 `start.careerdirect.kr`만 입력해도 과거 화면이 표시되지 않는다.
- 방문자는 무료 진로방향 자가진단 랜딩으로 이동한다.
- 기존 전환·운영 경로에는 변화가 없다.
