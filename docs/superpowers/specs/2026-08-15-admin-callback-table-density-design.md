# 관리자 콜백 목록 표 가독성 개선 설계

## 목적

관리자 콜백 목록에서 오른쪽 끝의 `운영 경고`와 `상태` 열을 일반 노트북 화면에서 가로 스크롤 없이 한눈에 확인할 수 있게 한다. 정보는 삭제하지 않고 날짜와 시간을 줄로 분리하고 열 폭과 여백을 재배분한다.

## 화면 기준

- 약 1280px 이상의 일반 노트북 화면에서 11개 열과 `상태` 열까지 기본 화면에 표시한다.
- 모바일과 좁은 화면에서는 11개 열을 과도하게 압축하지 않고 기존 가로 스크롤을 유지한다.
- 표 본문 글자 크기는 현재 수준을 유지해 가독성을 희생하지 않는다.

## 날짜·시간 표시

- 신청일은 한국시간 기준으로 두 줄 표시한다.
  - 첫 줄: `2026. 8. 15.`
  - 둘째 줄: `오전 9:38`
- 확정 일정도 한국시간 기준으로 날짜와 시간을 분리한다.
  - 첫 줄: `2026. 8. 17.`
  - 둘째 줄: `오전 10:00`
  - 셋째 줄: 일정 상태
- 초 단위는 목록에서 제거한다. 상세 화면과 데이터에는 원래 시각을 유지한다.
- 날짜·시간 포맷은 재사용 가능한 작은 함수로 분리해 신청일과 확정 일정에 같은 규칙을 적용한다.

## 표 밀도 조정

- 표 최소 폭을 현재 `1380px`에서 약 `1180px`로 줄인다.
- 셀 좌우 여백을 현재보다 소폭 줄인다.
- 신청일과 확정 일정은 날짜·시간 분리로 가로 폭을 절약한다.
- 연락처는 전화번호와 이메일의 기존 두 줄 구조를 유지한다.
- 희망 일정은 날짜와 희망 시간대를 기존처럼 두 줄로 유지한다.
- 결제·서비스·운영 경고·상태는 짧은 상태값이 불필요하게 여러 줄로 갈라지지 않도록 줄바꿈을 제한한다.
- 상담 주제의 최대 폭은 유지하되 필요한 경우 자연스럽게 줄바꿈한다.

## 동작과 데이터

- 데이터 조회, 필터, 링크, 결제·서비스·운영 상태 계산은 변경하지 않는다.
- 화면 표시만 바꾸며 저장 데이터와 관리자 업무 흐름에는 영향을 주지 않는다.
- 기존 행 배경색, 테스트/실고객 구분, 경고 배지와 상태 배지를 유지한다.

## 검증

- 날짜·시간 분리 함수의 오전·오후와 자정·정오 사례를 확인한다.
- 1280px 화면에서 `상태` 열까지 보이고 전체 문서에 가로 넘침이 없는지 확인한다.
- 모바일에서는 표 컨테이너 안에서만 가로 스크롤이 동작하는지 확인한다.
- 신청일, 확정 일정, 연락처, 결제, 서비스, 운영 경고와 상태 정보가 빠짐없이 표시되는지 확인한다.
- 린트, TypeScript와 프로덕션 빌드를 실행한다.

## 완료 기준

관리자가 일반 노트북 화면에서 신청일과 확정 일정의 날짜·시간을 쉽게 읽고, 같은 화면에서 오른쪽 끝 `상태`까지 확인할 수 있어야 한다. 모바일 가로 스크롤과 기존 운영 기능에는 회귀가 없어야 한다.
