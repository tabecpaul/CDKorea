# 네이버 채널 상세 텍스트 전용 표시 수정 설계

## 배경

채널별 콘텐츠 상세 화면은 현재 `Threads`만 이미지가 없는 채널로 분류하고,
네이버·Facebook·Instagram에는 모두 카드뉴스를 표시한다. 이 분류는 확정된
운영 방식과 다르다. 네이버 블로그는 장문 원고를 편집기에 옮기고 글 하단 CTA를
직접 연결하는 수동 발행 채널이며, 카드뉴스를 게시물 구성요소로 사용하지 않는다.

## 확정 채널 기준

| 채널 | 상세 화면의 주 콘텐츠 | 카드뉴스 표시 |
| --- | --- | --- |
| 네이버 블로그 | 장문 원고, 카테고리, CTA·UTM, 모바일 링크 확인, 수동 발행 완료 | 표시하지 않음 |
| Facebook | 공용 Meta 문안, 일정, CTA·UTM | 표시 |
| Instagram | 공용 Meta 문안, 일정, CTA·UTM | 표시 |
| Threads | Threads 문안, 일정, CTA·UTM | 표시하지 않음 |

## 변경 범위

1. `ChannelContentDetail`에서 카드뉴스 사용 채널을 Facebook과 Instagram으로만
   명시한다.
2. 네이버 채널 상세의 상단 카드뉴스 갤러리를 렌더링하지 않는다.
3. 네이버 상세에는 장문 원고와 기존 `NaverPublishingPanel`을 유지한다.
4. `NaverPublishingPanel` 내부에서도 카드뉴스 파일 목록이나 이미지 미리보기를
   표시하지 않는다. 원고·카테고리·CTA·UTM·두 가지 수동 확인·게시 URL·완료 기록만
   유지한다.
5. 전체 콘텐츠 검토 화면의 카드뉴스 미리보기, 수정본 업로드, 승인 기능은 그대로
   유지한다.
6. DB, API, 상태 머신, 자동 발행 여부와 외부 채널 게시 동작은 변경하지 않는다.

## 안내 문구

네이버 채널 상세에는 다음 취지의 짧은 안내를 표시한다.

> 네이버 블로그는 장문 원고와 글 하단 CTA 링크로 수동 발행합니다. 카드뉴스는 사용하지 않습니다.

Threads의 기존 텍스트 전용 안내는 유지한다.

## 검증

- 네이버 채널 상세에 `AssetPreviewGallery`와 카드뉴스 파일 목록이 없다.
- 네이버 장문 원고, 카테고리, CTA·UTM, 모바일 클릭 확인 및 수동 발행 완료 기능은
  그대로 동작한다.
- Facebook과 Instagram 채널 상세에는 카드뉴스가 계속 표시된다.
- Threads 채널 상세에는 카드뉴스가 표시되지 않는다.
- 전체 콘텐츠 검토 화면에는 카드뉴스와 승인 기능이 계속 표시된다.
- 기존 마케팅 테스트, 타입 검사, 린트와 Production 빌드가 통과한다.

## 비범위

- 네이버 글 자동 작성 또는 자동 게시
- 카드뉴스 자산 삭제
- 콘텐츠 데이터나 일정 변경
- 새로운 채널 기능 추가
