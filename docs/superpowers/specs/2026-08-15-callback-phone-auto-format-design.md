# 콜백 전화번호 자동 포맷 설계

## 목적

콜백 신청자가 휴대전화 번호를 숫자로 연속 입력해도 화면에서 읽기 쉬운 하이픈 형식으로 자동 표시한다. 기존 서버 검증과 저장 형식은 유지하고, 키보드 입력·모바일 숫자 키패드·붙여넣기에서 같은 결과를 제공한다.

## 입력 동작

- 전화번호 입력값에서 숫자 이외의 문자를 제거한다.
- 국내 휴대전화 번호에 필요한 최대 11자리까지만 유지한다.
- 입력 중인 숫자를 단계별로 표시한다.
  - 3자리 이하: 입력한 숫자를 그대로 표시한다.
  - 4–7자리: 앞 3자리 뒤에 하이픈을 넣는다.
  - 8–10자리: `3-3-나머지` 형식으로 표시한다.
  - 11자리: `3-4-4` 형식으로 표시한다.
- 사용자가 하이픈이나 공백을 직접 입력하거나 번호를 붙여넣어도 숫자를 다시 정규화해 같은 결과를 만든다.
- `inputMode="tel"`, 자동완성, 기존 레이블과 필수 입력 속성을 유지한다.

## 구조

- 순수 함수 `formatKoreanMobilePhone`을 콜백 기능의 별도 유틸리티 파일에 둔다.
- `CallbackForm`은 전화번호 표시값만 상태로 관리하고 `onChange`마다 포맷 함수를 적용한다.
- 제출 시 화면 값이 전송되지만 서버의 기존 `replace(/\D/g, "")` 정규화가 하이픈을 제거하므로 저장·중복 검사·유효성 검증 방식은 바뀌지 않는다.
- 외부 마스킹 라이브러리는 추가하지 않는다.

## 오류 처리

- 불완전하거나 국내 휴대전화 패턴에 맞지 않는 번호는 기존 `contact_invalid` 오류를 사용한다.
- 11자리를 넘는 숫자는 추가 입력되지 않도록 잘라낸다.
- 빈 값과 삭제 동작은 자연스럽게 허용하되 제출 시 필수 검증을 유지한다.

## 검증

- 포맷 함수에 숫자 길이별, 하이픈 포함 입력, 공백·문자 포함 입력, 11자리 초과 입력 단위 테스트를 추가한다.
- 콜백 폼에서 `01052311059` 입력 시 `010-5231-1059`가 표시되는지 확인한다.
- 모바일과 데스크톱에서 입력·삭제·붙여넣기와 가로 넘침을 확인한다.
- 린트, TypeScript와 프로덕션 빌드를 실행한다.

## 완료 기준

사용자가 숫자만 입력해도 전화번호가 실시간으로 올바르게 표시되고 기존 서버 제출이 정상 처리되어야 한다. 배포 후 지정한 테스트 신청이 성공 화면에 도달하며, 기존 사용자 미추적 파일은 수정하거나 커밋하지 않는다.
