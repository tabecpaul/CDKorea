# 네이버 채널 상세 원고 중복 제거 설계

## 문제

네이버 채널 상세에서 같은 `naverBody`가 두 번 표시된다.

1. 공통 채널 문안 영역의 `네이버 문안 / 네이버 원고`
2. 실제 발행 확인 기능이 있는 `네이버 수동 발행 / 네이버 원고`

이는 동일 콘텐츠를 반복해 화면을 길게 만들고 어느 영역을 기준으로 발행해야 하는지
혼동을 준다.

## 확정 설계

- 네이버 채널 상세에서는 공통 채널 문안 영역을 렌더링하지 않는다.
- 네이버 원고는 `NaverPublishingPanel` 안에서 한 번만 표시한다.
- 네이버 일정, CTA·UTM, 카테고리, 두 확인 항목, 게시 URL과 완료 기록은 그대로
  유지한다.
- Facebook·Instagram의 공용 Meta 문안과 Threads 문안은 현재 위치에 그대로
  표시한다.
- 전체 콘텐츠 검토 화면은 변경하지 않는다.

## 구현 경계

`ChannelContentDetail`의 공통 문안 섹션을 네이버가 아닐 때만 렌더링한다.
`NaverPublishingPanel`, API, DB, 상태 머신과 콘텐츠 데이터는 수정하지 않는다.

## 검증

- 네이버 채널 상세의 `naverBody` 표시 위치는 한 곳뿐이다.
- `네이버 문안` 제목은 네이버 채널 상세에서 사라진다.
- `네이버 수동 발행` 안의 `네이버 원고`는 유지된다.
- Facebook·Instagram·Threads 문안 영역은 유지된다.
- 카드뉴스 채널 정책과 전체 검토 화면은 변하지 않는다.
- 전체 마케팅 테스트, 타입 검사, 린트와 Production 빌드가 통과한다.

## 비범위

- 원고 내용 수정
- CTA 또는 일정 변경
- 자동 발행 추가
- DB·API 변경
